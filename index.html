點位用前一交易日的完整日 K 算出，當天開盤前就固定，盤中不必重算。本表用資料日收盤對照這組點位；同一組點位也可當隔天的參考價。

站上、跌破代表什麼

原始規則（摘自公開評分條件）：偏多評分看「收盤大於或等於昨天、前天的上軌、中軌、下軌」，以及是否「站上週守、上週守、本月守、上月守」，各計分。偏空評分看「收盤小於昨天、前天的上軌、中軌、下軌」，以及是否「跌破本週守、上週守、本月守、上月守」，各計分。原始規則也曾用「要扭轉短空，本週必須守住週守」這類說法，把週守當作當週扭轉空方的關鍵線。本頁列出的是本週守與本月守；上週守、上月守未顯示。

一般解讀（非原始規則原文，僅供對照）：上軌可看作短線偏強區或壓力，收盤站上上軌代表短線偏強；中軌可看作多空分界；下軌可看作支撐或弱勢區，收盤跌破下軌代表短線偏弱。介於中軌–上軌、介於下軌–中軌是中間地帶。站上週守、月守代表收盤守在該週、該月守價之上；跌破則相反。以上皆非投資建議。

個股點位

以代號或名稱搜尋，欄位可排序。點任一檔（或上方指數卡片）可打開日線圖看趨勢。每列「位置」為收盤相對上軌／中軌／下軌；週守、月守另以站上或跌破標示。篩選可看收盤站上上軌、跌破下軌，或同時站上週守與月守。

公式說明

H、L、C 為當日最高、最低、收盤。

中心 = (9H + 9L + 10C) / 28；上軌 = 中心 + (221/274)(H − L)；下軌 = 中心 − (221/274)(H − L)

Q = (13H + 13L + 10C) / 36；個股中軌 = (Q + 當日均價) / 2，均價 = 成交金額 ÷ 成交股數；指數與台指期近月（日盤）中軌 = Q

台指期全盤：上軌、中軌、下軌用夜盤加日盤到 13:40 為止的最高、最低、最後成交價（由期交所每日逐筆成交資料取得，約 16:45 公布，之前先以收盤估算）；中軌 = (Q + 同時段成交均價) / 2。週守、月守取本週、本月到當天夜盤為止的全盤最高、最低，C 取當天夜盤收盤。

標普500、納指、費半：與加權指數相同的指數算法（中軌 = Q），日期用美東交易日，週守、月守以美東的當週（週一起）與當月計算。資料來自 Nasdaq 公開歷史行情（官方日開高低收），備援為 Yahoo Finance。標普500目前 Nasdaq 指數 API 無資料，改用 Yahoo Finance 的 ^GSPC。

週守、月守 = (37HH + 37LL + 10C) / 84，HH、LL 為本週（週一起）或本月迄今的最高、最低，C 為最新收盤。

位置：收盤 ≥ 上軌為站上上軌；中軌 ≤ 收盤 ＜ 上軌為介於中軌–上軌；下軌 ＜ 收盤 ＜ 中軌為介於下軌–中軌；收盤 ≤ 下軌為跌破下軌。全部四捨五入到小數兩位。

資料來源：證交所每日收盤行情、櫃買中心每日收盤行情與櫃買指數月查詢（含開高低收）、證交所加權指數歷史、期交所台指期日盤與夜盤行情、期交所每日逐筆成交資料。依公開歷史行情獨立計算，僅供個人參考。
